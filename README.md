# 🫧 拼豆画板 - 马卡龙手工坊

一个可爱、温暖的在线拼豆图案设计工具，让你像玩像素画一样设计拼豆图案！

## ✨ 功能特色

- 🎨 **手动绘制** - 铅笔、橡皮、油漆桶、吸管等专业工具
- 📷 **图片转拼豆** - 拖拽上传照片，一键转换为拼豆图纸（K-Means算法 + Web Worker）
- 🪞 **对称绘画** - 开启垂直对称模式，自动镜像绘制
- 📋 **物料清单** - 自动统计每种颜色用量，导出CSV去采购
- 💾 **导出PNG** - 支持1x/2x/3x/4x分辨率导出
- 🎨 **专业色板** - 预置Perler和Hama两大品牌色板
- ↩️ **撤销/重做** - 支持50步历史记录
- 🔍 **缩放平移** - Ctrl+滚轮缩放，空格+拖拽平移

## 🛠️ 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

## 🚀 部署到 GitHub Pages

1. 将代码推送到 GitHub 仓库
2. 在仓库 Settings → Pages → Source 中选择 **GitHub Actions**
3. 推送到 `main` 分支即可自动构建部署
4. 如果仓库名不是 `BeadsCreator`，请修改 `vite.config.js` 中的 `base` 路径

## 🎮 操作指南

| 操作 | 方式 |
|------|------|
| 放置拼豆 | 左键点击/拖拽 |
| 擦除拼豆 | 右键点击 / 长按 |
| 缩放画布 | Ctrl + 滚轮 |
| 平移画布 | 空格 + 拖拽 |
| 撤销 | Ctrl + Z |
| 重做 | Ctrl + Shift + Z |

## 📦 技术栈

- React 19 + Vite 8
- 纯前端，所有计算在浏览器端完成
- Web Worker 处理图片像素化
- K-Means 聚类 + 拉普拉斯边缘检测
